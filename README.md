# pairwise-hrtf-binaural

双耳空间音频在玩家快速转头时声源定位滞后，HRTF 卷积用的头部朝向是上一帧，转向后左右耳先错位再追上；声源穿过头部时只做距离衰减，没做头部遮挡，脑后声源和正前方一样响；多声源共享一个卷积核，远近不同的声源被同一组 HRTF 抹平；混响尾音在声源停止后立即截断，房间切换时尾音还带着旧房间；采样率 48k 与 44.1k 路径的 HRTF 长度不同，重采样后双耳延迟不对称；声源移动到听者正后方时方位角在 ±180° 跳变，插值绕远路转一圈；异步加载 HRTF 数据集时主线程直接读半初始化缓冲，偶发爆音；遮挡射线只测静态几何，门打开后声音仍被挡住；声道映射把中置声道混进左耳，5.1 下对白偏左；性能降级时把 HRTF 换成单 tap，声像突然塌到中间。audio/spatial_audio.py 是核心，tests/test_spatial_audio.py 15个红。要修的是：头部朝向与音频帧对齐；加头部遮挡与绕射；按距离分组卷积；混响跨房间淡出；统一采样率与双耳延迟；方位角走最短弧；HRTF 加载加就绪屏障；遮挡测动态几何；中置按声道矩阵分配；降级保持双耳 cues。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
